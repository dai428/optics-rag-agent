# 偏振测量基础（公开示例语料）

> 本文件是**教学示例**，用于演示检索与引用能力，不包含任何未发表的研究数据。
> 所有数值均为教科书级公开常识或刻意构造的示例值。

## 1. Stokes 参量与偏振描述

偏振光常用 **Stokes 参量**（Stokes parameters）描述，记为列向量
`S = [S₀, S₁, S₂, S₃]ᵀ`，其中：

- `S₀`：总光强；
- `S₁`：水平与垂直方向的线偏振差；
- `S₂`：±45° 方向的线偏振差；
- `S₃`：圆偏振分量（右旋为正）。

完全偏振光满足 `S₀² = S₁² + S₂² + S₃²`；部分偏振光则用
**偏振度**（DOP = Degree of Polarization，偏振度）描述：

    DOP = √(S₁² + S₂² + S₃²) / S₀

DOP = 1 表示完全偏振，DOP = 0 表示完全非偏振。

## 2. 测量矩阵与条件数

偏振测量系统的核心是一个**测量矩阵** `A`（又称仪器矩阵或分析矩阵），
它把待测的入射 Stokes 向量映射为探测器读出的光强向量：

    I = A · S

要从测得的 `I` 反解出 `S`，需要求 `A` 的逆（或伪逆）：

    S = A⁻¹ · I

因此 `A` 的**条件数**（condition number）直接决定重建误差被放大的程度。
条件数 `κ₂` 定义为最大奇异值与最小奇异值之比：

    κ₂(A) = σ_max / σ_min

条件数越接近 1 越好。对 `N × 4` 的测量矩阵，`κ₂` 的理论下界是 **√3 ≈ 1.732**
（对应正四面体构型，即四个分析向量在 Poincaré 球上均匀分布）。

| 测量次数 N | 理论最小条件数 κ₂ | 说明 |
|---|---|---|
| 4 | 1.732 | 理论最优（正四面体），无冗余 |
| 6 | 约 1.8~2.0 | 有冗余，抗噪能力提升 |
| 8 | 约 2.0~2.5 | 冗余更多，但器件成本上升 |
| 12 | 约 2.5~3.0 | 工程上收益递减 |

> 结论：`N = 4` 是条件数最优解，但**没有冗余**，一次测量异常就会显著污染重建；
> `N = 6` 通常被认为是「精度与成本」的工程折中点。

## 3. 误差放大与噪声

重建误差与条件数满足近似关系：

    ‖ΔS‖ / ‖S‖ ≤ κ₂(A) · ‖ΔI‖ / ‖I‖

也就是说，条件数把**相对测量误差**线性放大到重建结果上。
若 `κ₂ = 2`，1% 的光强测量误差可能带来约 2% 的 Stokes 重建误差。

实际系统的误差源主要有三类：

1. **器件误差**：波片延迟量偏差、偏振片消光比不足；
2. **装调误差**：快轴方位角对准偏差（对条件数影响最大）；
3. **环境误差**：温度漂移导致延迟量随温度变化。

## 4. 液晶可变延迟器（LCVR）

**LCVR** = Liquid Crystal Variable Retarder，液晶可变延迟器。
它是一种向列相液晶器件：通过改变施加电压来调整液晶分子倾角，
从而连续改变对入射光的**相位延迟量** δ。

相位延迟量随波长与电压变化，基本关系为：

    δ(λ, V) = 2π · Δn(V) · d / λ

其中 `Δn(V)` 是电压控制的双折射率差，`d` 是液晶层厚度，`λ` 是波长。

相比传统的机械旋转波片，LCVR 的优势是：

- **无机械运动**：靠电压切换，重复性好、寿命长；
- **切换快**：典型响应时间在毫秒到数十毫秒量级；
- **可连续调节**：延迟量可任意设定，便于优化测量矩阵。

主要缺点是**温度敏感**：向列相液晶的双折射率随温度变化，
温度漂移会直接改变延迟量，进而使测量矩阵偏离设计值。

## 5. 温度效应的经验模型

延迟量随温度的变化在工程上常近似为线性：

    δ(λ, V, T) ≈ δ₀(λ, V) · [1 + c · (T − T₀)]

其中 `c` 是温度系数，`T₀` 是标定参考温度。
示例值（仅为演示）：若 `c ≈ -0.002 /℃`，温度变化 10 ℃ 会带来约 2% 的延迟量变化。

对高精度偏振测量而言，2% 的延迟量偏差足以让条件数明显恶化。
常见对策有两类：

1. **硬件补偿**：给 LCVR 加温控（成本高、体积大）；
2. **建模补偿**：把温度作为自变量纳入优化与标定（成本低，但需要温度模型）。

## 6. 标定流程要点

LCVR 偏振计的标定通常包含以下步骤：

1. **确定参考状态**：用已知偏振态（如完全线偏振）作为基准；
2. **扫描电压-延迟量曲线**：在目标波长下测 `δ(V)`；
3. **温度标定**：在不同温度下重复上一步，拟合温度系数；
4. **构建测量矩阵**：把各分析状态的 Stokes 向量组装成 `A`；
5. **验证条件数**：检查 `κ₂(A)` 是否接近设计目标；
6. **残差校验**：用独立已知偏振态检验重建精度。

> 注意：第 3 步常被省略。若系统工作在温度波动环境中而不做温度标定，
> 第 5 步算出的条件数只是「常温理想值」，实际性能会明显低于设计值。
