偏振测量与液晶可变延迟器（LCVR）基础知识

一、偏振光与斯托克斯参量
偏振是光的横波特性。完全偏振光可用斯托克斯参量（Stokes parameters）完整描述，记作 S = [S0, S1, S2, S3]。
其中 S0 表示总光强，S1 表示水平与垂直线偏振的分量差，S2 表示 ±45 度线偏振的分量差，S3 表示左旋与右旋圆偏振的分量差。
归一化后常用 [1, s1, s2, s3] 表示，偏振度 DoP = sqrt(s1^2 + s2^2 + s3^2)。

二、液晶可变延迟器 LCVR
液晶可变延迟器（Liquid Crystal Variable Retarder，LCVR）是一种基于液晶电光效应的相位延迟器件。
其原理是：对液晶盒施加不同电压，液晶分子取向改变，导致双折射量（即相位延迟量）随之改变。
因此 LCVR 可以通过调节电压来连续、精确地控制光束的相位延迟，而无需机械转动。
相比传统旋转波片，LCVR 的优势是：无机械运动部件、切换速度快（毫秒级）、可编程控制、重复性好。
LCVR 的延迟量随电压变化曲线通常呈非线性，需要预先标定（定标）——这是偏振仪校准中的关键步骤。

三、偏振仪与穆勒矩阵
偏振仪用于测量光束的偏振态（全 Stokes 检测）。
系统通常由偏振态发生器（PSG）和偏振态分析器（PSA）构成，二者均由偏振片与延迟器组合而成。
当延迟器使用 LCVR 时，通过改变施加电压即可获得不同的分析态，从而无需旋转元件就能完成全 Stokes 参量的测量。
穆勒矩阵（Mueller matrix）是 4x4 实数矩阵，描述光学元件或样品对偏振态的全部改变。
穆勒矩阵成像（Mueller matrix imaging）通过逐点测量穆勒矩阵，获取样品的偏振特性空间分布。
仪器矩阵（或称系统矩阵）的定标是偏振仪测量的核心问题——若定标不准，反演出的偏振态误差会显著放大。

四、计算偏振成像
计算偏振成像（Computational Polarization Imaging）将偏振测量与计算成像方法结合。
通过对测量数据进行逆问题求解，可以从欠采样的测量中重建完整的偏振信息。
常用方法包括最优化重建、正则化反演等。
偏振信息在雾霾穿透、表面缺陷检测、生物医学成像、目标识别等领域有独特优势。

五、偏振测量的典型误差来源
1. 延迟器的延迟量标定误差（LCVR 电压-延迟量关系不确定）。
2. 偏振片消光比有限、快轴方位角对准误差。
3. 探测器响应非均匀性与噪声。
4. 光源偏振态不稳定。
因此在偏振仪设计中，优化 LCVR 的配置（如延迟量工作点的选取）可以显著降低测量矩阵的条件数，提升反演精度。
